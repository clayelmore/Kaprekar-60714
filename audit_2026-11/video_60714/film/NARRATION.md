# Narration script (nine takes, one file each in assets/vo/)

Record or generate each take as its own file with the name shown. Numbers are written the way they should be said: as whole numbers, never digit by digit.

1. `01_four.wav`
   Take any four digits. Write them biggest to smallest, then subtract the same digits reversed. Keep doing that, and you always land on sixty-one seventy-four. That is Kaprekar's constant, found by the mathematician and schoolteacher D. R. Kaprekar in nineteen forty-nine.

2. `02_five.wav`
   So what about five digits? Let's try sixty thousand, seven hundred fourteen. Sort the digits, biggest first. Then the same rule: that number, minus its reverse. That gives seventy-four thousand, nine hundred forty-three.

3. `03_loop.wav`
   Keep going, and it never lands. It falls into a loop, and goes round and round forever.

4. `04_bulb.wav`
   But keep the same five notes, and just change the order. Start from the sorted digits again. The top row becomes A, D, C, B, E. That is seventy-one thousand, four hundred sixty. The bottom row becomes D, E, A, C, B. That is ten thousand, seven hundred forty-six. Now subtract.

5. `05_stays.wav`
   The answer is sixty thousand, seven hundred fourteen. The same number we started with. It stays.

   `05b_why.wav`
   Why sort first? Because without it, nothing works. We tried all seven thousand, one hundred forty ways to shuffle five digits without sorting. Not one of them sends every number to the same place.

   `05c_count.wav`
   And in our rule, every digit counts. There are shortcuts. This rule sends every five digit start to forty-five thousand. But two of its letters never move, so two of the five digits are simply ignored. In ours, every letter moves. No digit is ignored.

6. `06_run.wav`
   Try any other start. Say, fifty-eight thousand, one hundred ninety-six. Sort the digits, biggest first, and call them A to E. The top row becomes A, D, C, B, E. The bottom row becomes D, E, A, C, B. Then subtract.

7. `07_again.wav`
   Now take that answer, and do it again. Sort. Rearrange. Subtract.

8. `08_last.wav`
   And once more. Sort. Rearrange. Subtract. Sixty thousand, seven hundred fourteen. And from there, it never leaves.

   `08b_tree.wav`
   Here is every five digit start at once. Each line is one step. They all flow into the same place.

9. `09_claim.wav`
   We checked every five digit start by computer. Leave out the ten repeats, like eleven thousand, one hundred eleven, which drop to zero, and that is ninety-nine thousand, nine hundred ninety starts. Every one ends at sixty thousand, seven hundred fourteen. The longest trip is thirty steps. It is not Kaprekar's rule. It is the same idea, in a new order. We asked the questions.
